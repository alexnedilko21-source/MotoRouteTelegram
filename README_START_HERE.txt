МОТОМАРШРУТ — ПУБЛИЧНЫЙ GitHub, закрытые API-ключи

1. На GitHub создать Public репозиторий MotoRouteTelegram. НЕ добавлять ключи и токены ни в один файл, скриншот, коммит или README.
2. Загрузить в корень репозитория server.py, render.yaml, .gitignore, README_START_HERE.txt и папку static с index.html. НЕ загружать ZIP целиком.
3. На Render создать Blueprint из репозитория. При запросе задать секреты TELEGRAM_BOT_TOKEN и GEMINI_API_KEY через Environment. PUBLIC_MODE=1 задан в render.yaml.
4. Когда Render покажет Live, проверить https://<адрес>.onrender.com/health (ответ {"ok":true}).
5. В Telegram @BotFather выбрать /setmenubutton, выбрать бота, ввести подпись «🛵 Маршрут» и HTTPS URL Render.
6. Открыть бот в Telegram и кнопку меню. Для распознавания фото выбрать Gemini (в этой сборке выбран по умолчанию).
7. OCR может ошибаться: перед поездкой вручную сверять адреса и точки на карте. Навигация с поворотами только в Google Maps/Waze, по одной остановке.
8. Первая встроенная карта OpenStreetMap (iframe) доступна по умолчанию. Экспериментальный режим точек/GPS может давать серые плитки на некоторых сетях. Не используйте его как навигатор.
9. При выключенном Mac облачная версия на Render может продолжать работать. Бесплатный инстанс засыпает при простое.
10. Ранее опубликованный GEMINI_API_KEY скомпрометирован. Лучше отозвать его до публичного размещения; приватность GitHub сама по себе ключ не защитит.

Это MVP, не полностью протестированная дорожная навигация. Перед использованием в поездке выполните тесты на безопасной остановке.
